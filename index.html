Быстрый старт

  1. Настройте Google Cloud. Включите Sheets API, создайте API Key (для Viewer) и OAuth Client ID (для Editor). Подробная инструкция — в TODO.md.
  2. Откройте Editor и войдите через Google — при первом Pull появится запрос доступа к Sheets.
  3. Нажмите Pull — данные из таблицы загрузятся на холст.
  4. Рисуйте. Инструменты слева (или в drawer на мобильном), свойства объекта — справа (bottom sheet на мобильном).
  5. Push или Ctrl+S — сохранить изменения обратно в Google Sheets.
  6. Поделитесь ссылкой на viewer.html — зрители увидят схему без авторизации.

Формат SheetLang

Каждая схема хранится в Google Sheets как текст: одна строка таблицы = одна фигура. Строки, начинающиеся с #, — комментарии, пустые строки игнорируются.

Настройка Google Cloud

  1. Создайте проект на console.cloud.google.com.
  2. Включите Google Sheets API v4 в разделе APIs & Services → Library.
  3. Создайте API Key (restricted to Google Sheets API) → вставьте в CONFIG.apiKey в js/app.js.
  4. Создайте OAuth Client ID типа Web Application. Authorized JS origin: https://ваш-домен.github.io. Client ID → CONFIG.googleClientId в js/editor-app.js.
  5. Откройте Google Sheet → Share: Anyone with the link (Viewer) для публичного чтения, редакторов добавьте по email.
Безопасность. Авторизация в Editor полностью клиентская — роли можно подделать через консоль браузера. Не используйте для чувствительных данных. Подробнее — в AGENTS.md и TODO.md.
